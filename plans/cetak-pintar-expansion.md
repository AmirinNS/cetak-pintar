# Plan: CetakPintar expansion (rename, alphabet, picture themes)

## Goal

Turn CetakKira (math only) into CetakPintar, a printable A4 worksheet generator that covers math, the alphabet, and picture vocabulary themes (animals, fruits, vehicles, sports). Every new sheet keeps the current model: settings in the URL, seeded and deterministic, generated per request, answer key where one makes sense.

## Scope

- In scope:
  - Full rename to CetakPintar (code, metadata, UI, docs, Docker, tests). Work happens in a new folder `~/Projects/cetak-pintar` pushed to a new GitHub repo `AmirinNS/cetak-pintar`. The old `cetak-kira` folder and repo stay untouched.
  - Alphabet topics with no pictures: `trace` (letter tracing), `missing` (missing letter), `match` (upper/lower match).
  - Picture topics: `first_letter` (picture, write the first letter) and `guess_word` (picture, write the whole word).
  - Four themes of 12 items each (48 items), drawn as black-and-white line-art PNGs generated once, committed, and logged in `docs/assets.md`.
  - One new preset `abc`. Web form grouped into a math section and an alphabet section. CLI support for all new params.
- Out of scope:
  - Colouring sheets, word search, picture-word matching, more than four themes, cursive or Jawi script.
  - Rewriting old plans or the historical prompts in `docs/assets.md`.
  - Deployment, domain, and repo folder rename.

## Hard rules (carried from v1, extended)

1. Original content only. Questions are generated at runtime from a seed. Pictures are generated by an image model from prompts written for this project, with no copied workbook art, characters, brands, or logos. Every prompt is logged verbatim.
2. No personal paths, emails, or secrets in committed files (`tests/test_clean_repo.py` already enforces this).
3. No database. PDFs are never stored.
4. Narrow wording. Alphabet presets say "inspired by preschool and Tahun 1 literacy topics". Never claim KSSR alignment or ministry endorsement.
5. Words in both languages use A to Z only, are 3 to 8 letters long, and are single words (no "kereta api"). This keeps letter boxes and first-letter logic simple.

## Spec additions

New topics go after the math topics in the canonical order, so existing math links keep their topic order and RNG sequence:

`grid, count, add, sub, sifir_ref, sifir, div, trace, missing, match, first_letter, guess_word`

| Param | Default | Domain | Used by | Notes |
|---|---|---|---|---|
| `abc_case` | `upper` | `upper`, `lower` | `trace`, `missing` | `match` always pairs upper with lower |
| `missing_blanks` | 1 | 1 to 3 | `missing` | Blanks per row of 6 consecutive letters; never the first letter of a row |
| `themes` | `animals,fruits,vehicles,sports` | subset of those 4, at least 1 | `first_letter`, `guess_word` | Duplicates collapse, canonical order as listed |
| `guess_hint` | 1 | 0, 1 | `guess_word` | 1 prints the word's letters scrambled under the boxes |

- Options of unselected topics are dropped from the canonical query, the same as today.
- Error when the selected themes hold fewer items than one sheet needs (cannot happen with 12 per theme and at most 12 cards, but the check stays so a smaller theme cannot break it later).
- `abc` preset: `t=trace,missing,match,first_letter`, `abc_case=upper`, `missing_blanks=1`, all four themes.

## Page accounting changes

- `trace` takes part in round-robin like any practice topic but has no answer sheet. Add `NO_ANSWER_TOPICS = frozenset({"sifir_ref", "trace"})` in `modules/layout.py` and use it where the code checks `topic != "sifir_ref"` for answers. `sifir_ref` keeps its fixed sheet count.
- Cards per sheet: `trace` 4 letters (each row is one model letter plus dotted repeats), `missing` 12 rows, `match` 3 boxes of 6 pairs, `first_letter` 12, `guess_word` 8.
- `trace` is not random. Sheet `i` shows letters `4i` to `4i+3`, wrapping after Z. The other new topics use the shared `Random(seed)`.
- Picture topics sample items without replacement within a sheet from the pooled selected themes. Sheets may repeat items across sheets.
